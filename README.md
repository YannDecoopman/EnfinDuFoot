# Premier League Odds Comparison

A React application that compares Premier League betting odds from multiple bookmakers using Odds-API.io.

## Features

- Fetches upcoming Premier League matches with real-time odds
- Compares odds from Bet365, SingBet, and Unibet
- Highlights the best available odds for each outcome (Home Win, Draw, Away Win)
- Responsive table design with Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18+
- An API key from [Odds-API.io](https://odds-api.io/)

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Usage

1. Start the development server with `npm run dev`
2. Enter your Odds API key when prompted
3. View the comparison table showing odds from all bookmakers
4. Best odds for each outcome are highlighted with a star

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS

## API

This application uses [Odds-API.io](https://odds-api.io/) to fetch Premier League odds. See the [API documentation](https://docs.odds-api.io/) for more details.
